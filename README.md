# PV-Power-Matching

This is a final project undertaken at the Háskóli Íslands in winter of 2024. It analyzes how the orientation of photovoltaic panels can be chosen optimally to match the demand curve of a given load.
More preciselty, the project uses the cost of electricity for a given time period as optimizable function. Depending on what the retail price and the feed-in tariff of electricity is, the optimal solutions
vary. The optimization was done with a genetic algorithm approach due to the complexity of the problem.
